# Retail Sales Data Analysis Using Python

Exploratory data analysis of a retail sales dataset using Python (Pandas, NumPy, Matplotlib, Seaborn).

## Overview
This project analyzes retail sales data to uncover trends across categories, regions, products, customers, and time. It covers data cleaning, feature engineering, and visualization.

## What the analysis covers
- Data cleaning: checking for missing values and duplicates
- Feature engineering: shipping days, order year/month, profit margin
- Key metrics: total sales, total profit, total cost, total orders, average order value
- Sales and profit by category
- Top and bottom performing products
- Sales by region
- Top customers by sales
- Salesperson performance
- Sales breakdown by payment method
- Monthly sales trend
- Correlation between discount, sales, and profit
- Shipping days summary

## Tools used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files
- `Retail Sales Data Analysis Using Python.ipynb` — Jupyter notebook with the full analysis
- `Retail Sales Data Analysis Using Python.py` — Python script version
